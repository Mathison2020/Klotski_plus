# 华容道

一个完全在浏览器本地运行的华容道游戏，支持经典布局、半圆块、可原地旋转的 3/4 圆块、电话听筒形转角块、自动求解和自定义关卡编辑。

## 本地运行

```bash
bun install
bun run dev
```

访问终端显示的本地地址即可。项目没有服务端、账号系统或外部 API 依赖。

## 构建静态页面

```bash
bun run build
```

产物位于 `dist/`，可以放到任意静态文件服务器。资源路径使用相对路径，也支持直接部署在子目录。

## 其他命令

```bash
bun run test
bun run lint
bun run fmt
```

自定义关卡保存在当前浏览器的 `localStorage` 中，不会上传到服务器。
