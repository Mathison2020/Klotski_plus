# 新华容道

一款在经典华容道基础上加入可旋转异形滑块的益智游戏。除了熟悉的曹操、横将、竖将和小兵，棋盘中还会出现半圆块、3/4 圆块与听筒块，为腾挪路线带来更多变化。

[在线游玩](https://mathison2020.github.io/Klotski_plus/)

## 游戏目标

棋盘为 4 列 × 5 行。移动和旋转棋盘中的滑块，为 2×2 的曹操块清出通道，最终让它从棋盘底部中央的出口离开。

- 滑块不能越出棋盘，也不能与其他滑块占据同一个格子。
- 一次连续的直线移动计为一步，一次 90° 旋转或拐弯也计为一步。
- 手动操作和自动演示产生的步数都会计入当前累计步数。
- 从自动演示切回手动操作不会重置计步；只有重新开始关卡才会清零。

## 基本操作

- **移动：**按住滑块并拖动，松开后会自动吸附到合法的棋盘位置。
- **选择：**点击滑块可高亮当前选择，并显示可操作状态。
- **旋转异形块：**在支持旋转的块上按住右键拖动，沿希望的方向完成旋转或拐弯。
- **重新开始：**将当前关卡恢复到开局状态，并清空累计步数。
- **自动求解：**可以让程序计算解法，并使用播放、暂停、单步和速度控制查看完整过程；演示途中也可以随时接管棋盘。

## 滑块介绍

### 经典滑块

| 滑块 | 占用空间 | 说明 |
| --- | --- | --- |
| 曹操 | 2×2 | 目标滑块，需要移动到棋盘底部中央出口。 |
| 横将 | 2×1 | 横向长条滑块，可在空间允许时直线移动。 |
| 竖将 | 1×2 | 纵向长条滑块，可在空间允许时直线移动。 |
| 小兵 | 1×1 | 最灵活的基础滑块，常用于交换空位。 |

### 半圆块

半圆块占用相邻的两个格子，并有向上、向右、向下、向左四种开口朝向。它既可以直线移动，也可以围绕圆心原地旋转；旋转时，目标位置和旋转经过的区域都必须有足够空间。

### 3/4 圆块

3/4 圆块位于一个 2×2 区域内，但只占其中三个格子，整体呈带圆弧的 L 形，缺口可以朝向四个不同方向。其他滑块可以进入它未占用的缺口格。它能够正常平移，也能在空间允许时原地旋转 90°。

### 听筒块

听筒块占用连续三个格子，外形类似电话听筒。除了直线移动，它还可以利用半圆内凹一侧完成 90° 拐弯：按住右键拖动听筒的一端，让内侧拐角沿圆弧转入新的方向。整个转动路径必须保持畅通。

## 关卡与自动演示

游戏内置了经典布局和包含异形块的预设关卡。选择关卡后可以直接挑战，也可以启动自动求解器查看参考解法。自动演示会逐步还原求解路径，当前播放进度、累计步数和控制状态都会显示在界面中。

## 关卡编辑器

关卡编辑器可以创建自己的新华容道局面：

- 选择滑块种类和朝向时会显示形状预览。
- 鼠标悬停在棋盘上时，会以半透明效果预览滑块的摆放位置。
- 可以添加、移动、旋转或删除滑块，并检查局面是否满足棋盘约束。
- 自定义关卡会保存在当前浏览器中；清除该站点的浏览器数据后，本地关卡也会一并丢失。
- 编辑器支持将当前局面导出为 `KLP1` 编码字符串，也可以导入编码恢复局面，方便保存和分享关卡。

导入与导出功能只在关卡编辑器中提供，不会出现在游玩界面。
